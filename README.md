# Atlas Academy Mission Control - Module 0 Demo

This is the recovered Mission Control browser prototype updated with **M0-L01 - Welcome to Atlas Academy** and the production-ready staging build for **M0-L02 - Meet Atlas, Your Guide**.

## Open the demo

Open `index.html` in Chrome or Edge. The lesson video and PDFs are stored locally beside the site, so the demo does not require a repository or development server.

## Connected lesson assets

- Completed HeyGen Atlas lesson video with captions
- M0-L01 Student Workbook
- 30-Day Mission Tracker
- Academy Folder Setup Guide
- Lesson thumbnail
- Mission Complete screen
- Five-question quiz
- Reflection field
- Atlas prompt and response field
- Lesson notes

## Working prototype behavior

Progress is stored in the current browser. A student must:

1. Finish the video.
2. Open all three downloads.
3. Save the reflection.
4. Save the Atlas response.
5. Pass the quiz with at least 80%.

The Complete Mission button then awards 100 XP, begins Atlas Explorer badge progress, and unlocks M0-L02 in the local demo.

## M0-L02 production status

M0-L02 includes:

- Approved Atlas script and seven-scene HeyGen plan

## Production limitations

This remains a local prototype. Browser storage simulates student data. A production version still needs authentication, database persistence, secure server-side quiz scoring, file storage, Atlas AI access, enrollment permissions, and administrator reporting.
